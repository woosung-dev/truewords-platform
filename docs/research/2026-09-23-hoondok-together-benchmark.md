# 훈독 "함께 읽는 사람들" 벤치마크 (2026-09-23)

- 목적: 훈독 PWA 의 "함께" 기능(`DEC-PWA-023`) 설계 근거를 한 문서로 남긴다
- 입력: 같은 날 수행한 조사 3건(가정연합 훈독 문화·조직·민감성 / 초원·한국 종교 앱 / 외부 19앱 패턴과 내부 데이터 모델)을 압축했다. 원 조사 파일은 레포 밖 세션 산출물이다
- 결과물: 프로토타입 [`prototypes/hoondok-ds`](../prd/prototypes/hoondok-ds/README.md) `?screen=group` 외 3화면과 홈·훈독하기 변형(`?together=`)
- 표기: 라벨 없는 문장은 출처로 확인한 사실이다. `[가정]` 은 추론, `[확인 필요]` 는 사용자·협회가 정할 항목이다. 교리 평가는 하지 않는다

## 1. 사용자 결정 (2026-09-23 인터뷰, 재논의 금지)

| # | 결정 |
|---|---|
| 1 | 단계: **1단계 익명 숫자** "오늘 새벽 함께 읽은 식구 N명" → **2단계 초대 모임** |
| 2 | 모임 안에서는 **완료한 사람만** 보인다. 미완료자의 이름·상태·"아직" 없음. 독촉 알림·순위·점수·보상 없음 |

| 6 | 표시 이름은 **모임별**로, 들어갈 때 정한다(실명·애칭 자유) |

## 4. 가져올 것 / 피할 것

### 가져올 것

1. **익명 합계 숫자.** 개인을 드러내지 않고 "혼자가 아니다" 를 준다(초원 공동체 칭찬의 대부분이 이 층).
2. **의례 순서에 붙이기.** "훈독 → 대화 → 보고기도" 의 대화 = 한 줄 나눔, 보고 = 읽음 표시. 새 행동을 가르치지 않는다.
3. **N일차 공동 진행.** 교구가 이미 매일 "N일차" 를 센다. 개인 streak 보다 문화에 맞다.
4. **복귀 문을 제품이 연다.** "하루 쉬어도 정성은 이어져요. 오늘부터 다시 함께" 를 기본 문구로(카톡 통독방 3지점 ②).
5. **오늘 범위를 모임이 공유.** 교구 영상 설명란의 "교재+쪽수" 관행. 공식 편성 또는 리더가 원문 단락 범위를 지정.
6. **초대 코드 폐쇄 모임 + 모임별 표시 이름.** 일본 HanaLink 도 폐쇄형이다. 모임 이름은 별칭, 교회명 강요 없음.
7. **카카오톡 초대 링크.** 교회 공유는 이미 카톡에서 일어난다(갓피플도 카톡 초대링크).

### 피할 것

1. **미완료자 명단·"아직"·재촉 버튼·독촉 알림** (현행 프로토타입 홈·챌린지에 있었다 → 이번에 제거).
2. **교회 소속 수집·교회 간 숫자 비교·교회 랭킹** (초원 "우리 교회 랭킹").
3. **개인 진도율 순위표** (초원 공동체 통독 1·2·3위).
4. **현금성 보상·초대 보상** (초원 달란트 → "쇼핑몰인지 성경앱인지").
5. **공동 처벌·늦음 표시** (Forest, BeReal).
6. **자유 댓글** (생명의 삶 구걸·사칭). 반응 1종만.
7. **공유 카드에 말씀 본문 전체** (광언사 무단 배포 경고). 출처·짧은 인용·앱 링크만 `[확인 필요]` 협회 허용 범위.
8. **큰 UI 개편으로 고령층 이탈** (PRS 사례).

| 오늘 말씀 | `DailyReading(reading_date unique)` 전원 동일 | "같은 말씀을 읽었어요" 가 성립 |
| 초대 코드 | 전역 베타 게이트 1개(`HOONDOK_INVITE_CODE`) | 모임 초대 코드는 **별개**의 새 모델 필요 |
| 교회·가족·모임 | 없음 | 2단계는 모임·멤버·모임별 표시 이름·정성·한 줄·반응 모델이 새로 필요 `[가정]` 구현 계획에서 설계 |
