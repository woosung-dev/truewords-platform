# 휴대폰 PWA 테스트

안내받은 **HTTPS 접속 주소와 테스트 계정**을 사용한다. USB 연결은 필요 없다.
로컬 테스트는 Mac과 터널이 실행 중이어야 한다. 로컬 주소와 운영 주소의 앱·로그인은 별개다.
테스트 기능이 꺼져 있거나 계정이 허용 목록에 없으면 테스트 버튼이 보이지 않는다.

## 1. 설치와 알림 켜기 — 기기당 약 3분

1. iPhone은 Safari, Android는 Chrome에서 안내받은 주소의 `/hoondok`을 연다.
2. 홈 화면에 추가한다. iPhone은 공유 메뉴의 ‘홈 화면에 추가’, Android는 브라우저 메뉴의 설치 항목을 사용한다.
3. 홈 화면 아이콘으로 다시 열고 테스트 계정으로 로그인한다.
4. 설정 → 알림에서 ‘훈독하기’를 켜고 권한 요청을 허용한다. Android가 앱 알림 권한을 별도로 물으면 그것도 허용한다.
5. ‘테스트 알림’ 영역에 보안 연결·설치 앱·서비스워커 준비됨·이 기기 구독 있음이 표시되는지 확인한다. 집중 모드·방해 금지는 우선 끈다.

합격: 주소창 없는 앱에서 설정이 열리고 알림 권한과 이 기기 구독이 확인된다.
iPhone의 일반 Safari 탭에서 알림을 켤 수 없다는 안내는 정상이다.

## 2. 실제 알림 도착 — 기기당 약 20분

각 알림을 확인한 다음 다음 테스트를 시작한다. 대기 예약이 있으면 먼저 취소한다.
예약 예정 시각과 실제 알림 표시 시각을 적는다. ‘푸시 서비스 접수’만으로 도착 성공으로 체크하지 않는다.

| 순서 | 버튼·휴대폰 상태 | 확인할 결과 |
|---|---|---|
| 1 | ‘지금 (1분 이내)’를 누르고 앱을 계속 본다 | ‘테스트 알림이에요’ 도착. 알림을 누르면 책갈피 화면으로 이동 |
| 2 | ‘5분 뒤’를 누르고 다른 앱을 사용한다 | 앱으로 돌아오지 않아도 알림 도착. 탭하면 훈독 앱이 열림 |
| 3 | ‘10분 뒤’를 누르고 앱 전환 화면에서 훈독을 닫은 뒤 화면을 잠근다 | 잠금 상태에서 알림 도착. 잠금 해제 후 탭하면 훈독 앱이 열림 |
| 4 | 직접 입력에 `1`을 넣어 예약하고 곧바로 ‘예약 취소’를 누른다 | 취소됨 표시. 3분 기다려도 해당 알림 없음 |
| 5 | iPhone에서만 예약하고 Android도 켜 둔다 | iPhone에만 테스트 알림 도착. Android는 반대 방향으로도 확인 |

예약 시각에서 약 90초가 지나도 전송이 시작되지 않거나, 접수 뒤 2분을 넘겨도 도착하지 않으면
‘실패/지연’으로 적고 시각과 화면 상태를 알려준다. 다시 여러 번 누르지 않는다.
기기당 대기 예약은 하나, 계정당 한 시간에 6번까지다. 같은 계정을 두 기기에서 쓰면 횟수가 합산된다.
집중 모드·알림 요약·방해 금지·절전 때문에 소리나 배너가 없으면 알림 센터에도 있는지 확인한다.

## 3. 앱의 기본 동작 — 기기당 약 5분

1. 앱을 닫았다가 홈 화면 아이콘으로 다시 연다. 로그인과 화면이 정상인지 확인한다.
2. 온라인에서 홈과 설정을 한 번 연 뒤 비행기 모드로 전환한다. 앱 안에서 다른 화면으로 이동할 때 오프라인 안내가 나오는지 확인한다. 첫 설치부터 오프라인이면 이 검증을 할 수 없다.
3. 비행기 모드를 끄고 다시 홈을 연다. 오류 화면에 갇히지 않는지 확인한다.
4. 알림을 끈 다음 테스트 예약을 시도한다. 발송되지 않고 먼저 알림을 켜라는 안내가 나오는지 확인한다.
5. 업데이트 배포 안내를 받은 뒤 기존 설치 앱을 다시 연다. 새 테스트 화면이 보이고 다시 설치하지 않아도 정상 동작하는지 확인한다.

## 4. 정규 알림과 야간 대기 — 다음 날 확인

1. 당일 읽기를 완료하지 않은 테스트 계정에서 정규 훈독 시간을 다음 5분 경계로 맞춘다. 예: 현재 14:12라면 14:15. 발송 가능한 오늘 편성이 있는지는 담당자가 먼저 확인한다.
2. 앱을 닫고 잠근다. ‘테스트 알림’이 아닌 정규 책갈피 알림이 오는지 확인한다.
3. 알림을 지운 뒤 다음 5분 실행이 지나도 같은 날 중복 알림이 없는지 확인한다.
4. 다음 날 아침 시간을 설정하고 휴대폰을 8시간 이상 사용하지 않은 뒤 아침 알림이 왔는지 확인한다. 이 검증 중 Mac은 잠들지 않고 실행 중이어야 한다.
5. 집중 모드·절전 상태에서의 수신은 별도 결과로 기록한다. 기본 상태 결과와 섞지 않는다.

```text
환경: 로컬 / 배포
기기: iPhone 또는 Android 모델 / OS 버전 / Safari·Chrome 버전
설치·권한: 성공 / 실패 (어느 단계인지)
지금: 예정 HH:MM / 도착 HH:MM / 알림 탭 성공·실패
5분: 예정 HH:MM / 도착 HH:MM / 알림 탭 성공·실패
10분·종료·잠금: 예정 HH:MM / 도착 HH:MM / 알림 탭 성공·실패
취소·기기 구분: 성공 / 실패 / 미수행
재실행·오프라인·복귀·업데이트: 각각 성공 / 실패 / 미수행
정규·중복 방지·야간: 각각 성공 / 실패 / 미수행
```
