# [폐기] PC(데스크톱) 챗 시안 4안 — 구조 요약만 보존

> **2026-09-14 폐기.** HTML 시안 9개(챗 4안 × 3상태 + 소개 4안 + 비교 보드, 약 467KB)는 삭제했고 이 구조 요약만 남긴다.
>
> **폐기 사유:** 4안 전부 3-pane 정보구조 재설계(좌 세션 레일 + 중앙 대화 + 우 원문 패널)인데, 채택된 전략은 **D→A 순차**(계측 우선 → 반응형 단일 뷰)다. A안은 "모바일 골격을 유지하고 breakpoint 로 분기한다"이므로 시안의 전제와 정면으로 어긋난다.
>
> 추가로 시안이 공통 채택한 PC 레버 중 **P0-3(문장↔청크 각주 정렬)·P0-4(호버 프리뷰)는 `ChatSourcesEvent` 스키마 확장이 선행돼야 하는 백엔드 작업**이라, 설령 3-pane 으로 가더라도 이 시안을 그대로 쓸 수 없다.
>
> 4~8주 뒤 계측 데이터가 데스크톱 사용을 유의미하게 보이면, 확정된 기기 데이터와 확정된 `DEC-PWA-017` 정보구조 위에서 새로 뽑는다.

## 배경

`apps/web` 챗 화면(`src/app/(chat)/page.tsx`)은 본문·입력·footer가 모두 `mx-auto max-w-2xl`(672px)로 고정된 **모바일 우선 단일 컬럼**이며, 데스크톱 breakpoint 분기가 사실상 없다. 1440px 모니터에서 중앙 672px만 쓰이고 좌우가 빈다.

이 4안은 **기능을 바꾸지 않고** 화면 배치·시각 언어만 데스크톱용으로 재설계한 제안물이다. 서로 다른 디자인 스킬 4종으로 제작해 비교·선택한다.

## 소개 페이지 (`/about`) 4안

카피는 `apps/web/src/app/about/page.tsx` 전량 그대로다. 챗 시안과 달리 **문서·소개 성격**이라 세로 스크롤을 허용하되, 랜딩 문법(가격·테스티모니얼·전환 CTA·마케팅 카피)은 금지했다.

| 시안 | 레이아웃 | 특징 |
|:---:|---|---|
| **A** | 240px sticky 색인 거터 + 본문. 원칙마다 `124px 라벨 \| 본문` 2트랙 | 면책 장만 난색 지면 + 3px 악센트 좌보더로 시각 분리 |
| **B** | 220px 목차 레일(읽은 항목 게이지) + `라벨·본문·마진노트` 5트랙 | 마진노트에 **"챗 화면 대응 UI"** — 각 원칙이 챗 화면 어디에 구현됐는지 매핑 |
| **C** | 240px sticky 목차 + `라벨 180px / 본문 660px` 2트랙 | 원칙 4개를 상단 4열 카드로 요약한 뒤 본문 전개. 앰버 근거 채널 유지 |
| **D** | Double-Bezel 목차 셸 + 본문. 원칙마다 "챗 화면에서" 연결 카드 | 크림 지면 + grain, 세리프 번호. 가장 정적인 톤 |

공통 PC 레버: **좌측 sticky 목차 + 스크롤 스파이**, **읽기 진행 바**, **원칙↔챗 화면 상호 참조**(B·D는 마진노트/카드, A·C는 목차 하이라이트), **본문 measure 제어**(40~51자/행).

> **검수 통계 수치는 어느 시안에도 없다.** 해당 섹션은 운영 인력(신학 자문 4명) 미확보로 `page.tsx`에서 제거된 상태이며, 지어내면 허위 정보이므로 브리프·검수 양쪽에서 금지했다.

## 평가 축 (결정 시 사용)

1. **인용 추적성 (×2 가중)** — 주장→근거 원문 도달 비용 + 동시 표시 여부
2. **1440px 가로 폭 활용 효율** — 본문 한글 40~55자/행 유지하면서 남은 폭이 실사용 정보로 채워졌는가
3. **읽기 지구력** — 3천 자 신학 답변 10분 정독 피로도
4. **대화 연속성 + 스트리밍 제어** — 세션·턴·컨텍스트 잔량 가시성, 중단/재개 명확성
5. **구현 현실성** — Next.js + Tailwind + shadcn + SSE + 기존 RAG 응답 스키마로 2주 내 가능한가
