## 1. 이 문서가 답하는 질문

"초원AI처럼 익숙하되 AI가 만든 티가 나지 않고, iPhone에서 자연스럽고, 따뜻한 우리 앱"을 어떤 시각 언어로 만들 것인가. v1(#261)은 정보구조가 다른 3안을 비교했고 시안 완성도로 반려됐다. v2는 **정보구조를 PRD v2의 5탭으로 고정**하고, 같은 6화면·같은 예시 데이터 위에서 **시각 언어 2안**만 비교한다. 사용자가 고를 것은 "어떤 앱이냐"가 아니라 "어떤 얼굴이냐"다.

## 2. 두 안 공통 기준

### 2.1 iPhone 기준

- 논리 해상도 393×852 (iPhone 15/16 계열), Dynamic Island, 상태바 9:41, 하단 탭바 83px(49 + 홈 인디케이터 영역 34), 상단 안전 영역 59px.
- iOS HIG 문법: Large Title, inset grouped 카드 또는 구분선, 세그먼트 컨트롤, 하단 탭 5개(아이콘 + 라벨), 44pt 이상 터치 영역, 텍스트 대비 4.5:1 이상.
- 가운데 탭 "말씀"은 초원의 "성경" 탭처럼 강조하되, 초원식 원형 돌출 버튼은 쓰지 않는다.

### 2.2 서체와 아이콘

| 용도 | 안 A | 안 B |

| UI (탭, 버튼, 메타) | Pretendard Variable | Pretendard Variable |
| 화면 제목 | Pretendard 700 | Noto Serif KR 700 |
| 말씀 본문·인용 | Noto Serif KR 400, 18px, 행간 1.85 | Noto Serif KR 400, 19px, 행간 1.9 |

명조(세리프)는 "경전은 서책"이라는 도메인 관례 때문에 말씀 본문에만 허용한다. UI 전체를 명조로 하지 않는다. Pretendard는 현재 `apps/web`이 이미 CDN으로 쓰는 서체다. 아이콘은 Phosphor(1.5 stroke, 탭 활성은 fill)로 통일하고 이모지·손으로 그린 SVG·Lucide를 쓰지 않는다.

### 3.1 안 A 아침 햇살

- 오늘 화면 상단만 살구빛 라디얼로 "아침 창가"를 만들고 나머지는 흰 카드다. 3카드(말씀 읽기·보고기도·묵상 한 줄)는 초원의 3카드와 같은 위치에 있어 전환 학습이 필요 없다.
- 감(persimmon) 1색은 완료 체크·탭 활성·버튼에만 쓴다. 초원의 녹색 연속일·황토 버튼과 겹치지 않는다.
- 위험: 밝은 카드 루틴 앱이 많아 "우리 것"이라는 느낌은 문구와 콘텐츠가 만들어야 한다.

### 3.2 안 B 한지와 먹

- 종이 바탕 위에 명조 제목과 먹선. 오늘의 말씀이 카드가 아니라 **페이지의 본문**처럼 놓인다. 3카드는 먹선으로 나눈 행이다.
- 쪽빛 1색은 링크·완료·탭 활성에만 쓴다. 살구 틴트는 오늘 섹션과 인용 블록에만 깔아 따뜻함을 유지한다.
- 위험: 청년에게 "어른 앱"으로 보일 수 있다. 여백과 큰 명조 제목으로 무겁지 않게 잡았고, S2 인터뷰에서 `HYP-PWA-006`과 함께 확인한다.

## 4. 추천 `[제안]`

**B 한지와 먹을 채택하고, A의 오늘 화면 상단 살구빛과 3카드 완료 체크 감각만 B에 가져온다.**

1. 승인된 차별화는 "출처와 원문으로 돌려보낸다"이며, B는 말씀을 책처럼 보여 주어 그 정체성이 화면 자체에 있다. A는 콘텐츠를 바꿔도 초원과 같은 종류의 앱으로 읽힌다.
2. 사용자가 반려한 v1의 인상("AI가 만든 듯한 시안")에서 가장 멀다. 먹선·명조·여백은 생성형 디자인의 기본값(카드·그라디언트·둥근 모서리)과 반대 방향이다.
3. 다크 모드(저녁 보고기도 시간대)로 확장할 때 종이·먹 반전이 자연스럽다. A는 살구빛을 잃으면 평범해진다.
4. 청년 친화성은 B의 위험이므로, A의 살구 틴트와 완료 체크의 활기를 B의 오늘 화면에만 얹어 보완한다.

사용자가 A를 고르면 살구빛 헤더의 다크 모드 대안을 S3 진입 조건에 추가한다. B를 고르면 청년 5명 이상 인터뷰(`HYP-PWA-006`)를 S3 전에 실행한다.

## 6. 프로토타입 제작 기준

- 파일당 단일 HTML, 인라인 CSS, 외부 의존은 서체 2개(Pretendard jsdelivr, Noto Serif KR Google Fonts)와 Phosphor 아이콘 CSS뿐이다. 브라우저에서 파일을 열면 1440px에서 3×2 보드, 1024px 이하에서 1열로 접힌다.
- 각 폰은 정적 화면이다. 탭·버튼은 눌리는 상태만 있고 화면 전환은 없다(S3 디자인 시스템에서 인터랙션 정의).
- 스크린샷은 [`capture-screens.mjs`](prototypes/capture-screens.mjs)로 각 폰 요소를 2배 해상도로 캡처했다. 재현: 저장소 루트에서 `pnpm install --frozen-lockfile` 후 `node docs/prd/prototypes/capture-screens.mjs`.
- 라이트 테마만 만들었다. 다크·큰 글씨·고대비·reduced-motion은 채택안 기준으로 S3에서 정의한다.
- 접근성 최소선: 탭은 아이콘+텍스트, 완료 상태는 체크 아이콘+라벨, 권위 층은 라벨+형태, 본문 대비 4.5:1 이상(§3 실측).
