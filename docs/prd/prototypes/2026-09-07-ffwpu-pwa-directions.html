추천도

★★★☆☆ 승인된 차별화 문장("가족 실천까지 연결")을 가장 직접 구현하지만, 공유·가족 범위의 권리·아동 보호·운영 책임이 확정되기 전에는 MVP로 앞세우기 어렵다.

강점

  • 읽기가 "우리 가정의 실천"으로 끝나 초원의 개인 QT와 다른 정체성을 만든다.
  • 저녁 훈독·큰 글씨·가정에서 읽기 모드가 고령·가족 단위 사용 맥락에 맞는다.
  • 나눔 카드가 게이미피케이션 없이 자연스러운 확산 경로를 만든다.

위험

  • 공유 카드는 콘텐츠별 공유 권리와 철회 재확인이 필요해 권리 원장 의존이 가장 크다.
  • 가족 초대·그룹은 MVP 비범위라 "준비 중"이 오래 남으면 기대와 어긋난다.
  • 다크 테마는 저녁 맥락엔 맞지만 고령 사용자 기본값으로는 라이트 변형 검증이 필요하다.

세 방향 공통으로 검증할 과업

  1. 오늘의 말씀을 3분 안에 읽고 저장 또는 저장 안 함을 고른다.
  2. 질문 뒤 AI 설명과 공식 원문을 구분하고 화자·날짜·판본·공식성·검수 상태를 찾는다.
  3. 낯선 용어를 열어 복수 정의를 보고 관련 원문으로 이동한다.
  4. 철회된 콘텐츠와 근거 부족 상태를 오류와 구분해 설명한다.
  5. 설치·알림 제안의 시점과 중립 잠금 화면 문구를 설명하고 허용 또는 거부한다.

세 방향에 공통 적용한 규칙

  1. AI 설명·공식 원문·공식 해설·내 메모는 라벨과 형태로 구분한다. 색만으로 구분하지 않는다.
  2. 확인되지 않은 메타데이터는 추정값 대신 "확인되지 않음"으로 표시한다.
  3. 질문은 기본 저장 안 함이며, 저장은 사용자가 고른다.
  4. 설치·알림은 첫 읽기 또는 저장 뒤에만 제안하고 잠금 화면 문구는 중립형이다.
  5. 출석·점수·연속 기록·달란트형 보상을 두지 않는다.
