# 훈독 디자인 검토 기록

[index.html](index.html)을 브라우저로 열면 대안 A/B/C, B 수정안의 선택·제외 이유, 31개 페이지의 전후 화면과 반복 심사 이력을 볼 수 있다. 다른 사람에게 전달할 때는 이 폴더 전체를 복사한다. 외부 서비스나 CDN 없이 동작하며, 이미지는 합성·테스트 데이터만 포함한다.

1. **대안 비교:** 세 원형을 보존했다. 최종안은 B 그대로가 아니라 출처 첫 줄을 지키도록 수정한 안이다. 원형 B의 제목 선행은 채택하지 않았다.
2. **전후 비교:** 390·768·1280px의 같은 폭끼리 비교한다. 화면별 목적·주 행동·두 심사 점수·0~4 항목별 등급·결함 수정 이력을 함께 확인한다. 원본은 `0ef11993`을 별도 서버에서 실행해 촬영했다.
3. **판정 범위:** 10~20년차 시니어 관점을 가정한 독립 AI 역할 평가다. 공식 스킬 점수·사람 전문가의 인증·사용자 연구가 아니다. 두 심사 각각 75점과 실제 과업·접근성 검증을 별도로 다룬다.
4. **실행 증거:** [validation-details.json](validation-details.json)에 접근성 원래 결과와 처리, 공유·메모 검사, 성능의 실제 DevTools 제한과 기본 simulate 결과를 함께 남겼다. 성능 측정 방법이 다른 수치를 전후 개선율로 비교하지 않는다.
5. **추적:** [evidence-manifest.json](evidence-manifest.json)의 `reviewCommit`은 심사한 구현 커밋이며, 이후 기록 전용 커밋과 구별한다. 각 이미지의 SHA-256으로 당시 증거를 확인할 수 있다. 후속 검토는 기존 증거를 덮어쓰기보다 새 검토 폴더를 사용한다.

직접 파일 열기를 제한하는 브라우저에서는 저장소 루트에서 `python3 -m http.server 4874 --directory docs/design-reviews/hoondok --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:4874/`를 연다. 프리뷰 화면은 실제 접수·저장이 아니며, 공유 시각 자료와 실제 프리뷰 OFF의 이미지 응답 검증도 구분했다. 실제 외부 앱 전송·실제 iPhone·Safari·스크린리더 전체 인증·운영 CWV/INP 측정은 포함하지 않는다.
