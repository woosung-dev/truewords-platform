훈독 디자인 검토

페이지의 목적에 맞는 구성과 읽기 경험을 비교하고, 선택의 근거를 남깁니다.

어떤 방향을 비교했는가

화면을 다르게 구성한 이유와 최종 선택의 근거를 함께 봅니다. 이미지를 누르면 원본 크기로 확인할 수 있습니다.

페이지별 변경과 재검토

전체 평균 대신 각 페이지의 UI/UX와 디자인 점수를 확인합니다. 제목을 열면 목적, 변경 전후 이미지, 검사 결과가 나옵니다.

조건에 맞는 화면이 없습니다. 검색어나 검토 상태를 바꿔 주세요.

점수는 어떻게 정했는가

두 스킬을 참고해 이 작업에 맞게 고정한 평가표입니다. 스킬이 제공하는 공식 점수나 실제 사용자 검증 결과를 뜻하지 않습니다.

산식: 각 항목의 0~4 등급을 배점에 환산해 더합니다. 0은 실패, 1은 심각한 부족, 2는 부분 충족, 3은 충족, 4는 정교하게 충족입니다. UI/UX와 디자인이 각각 75점 이상이어야 합니다.

점수 외 통과 조건: 주요 행동 실패, 가림, 접근 불가, 핵심 대비 실패, 권리·정보 위계 오인과 같은 중대 결함이 없어야 합니다. 점수·증거·검사 기록이 부족하면 미검증으로 남깁니다.

적용 범위: UI/UX Pro Max의 제품 사용성 기준과 Taste의 적용 가능한 미학·카피·장식 검사를 사용합니다. 랜딩 페이지 전용 규칙을 제품 화면에 그대로 적용하지 않습니다.
