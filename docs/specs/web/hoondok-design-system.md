## 3. 간격·모서리·그림자·모션

- 간격: 화면 좌우 18px, 카드 패딩 16px, 섹션 간 18px(`.h` 상단), 리스트 항목 간 10px
- 모서리: `--r-lg` 20px(카드·포스트), `--r-md` 14px(버튼·입력·아이템), `--r-sm` 10px(세그먼트·작은 버튼), 칩·입력 바 pill, 시트 26px 상단, 9:16 카드 24px

- 터치 타깃: 버튼 46px, 작은 버튼 38px, 칩 38px(큰 글씨 42px), 탭바 항목 44px 이상, 아이콘 단독 액션은 40px 원형

## 5. 접근성·상태

- 큰 글씨 모드: 본문 17px, 말씀 22px/2.0, 메타 14px. 고정 높이 컨테이너 금지(모든 카드·시트는 내용 높이).
- 고대비: 다크 모드가 고대비 역할을 겸하되, S3 에서 별도 고대비 팔레트 필요 여부 결정 `[확인 필요]`.
- 키보드: 데스크톱 쉘에서 <kbd>D</kbd> <kbd>B</kbd> <kbd>←</kbd> <kbd>Esc</kbd>. 실제 구현에서는 모든 칩·세그먼트·토글에 포커스 링(2px primary offset 2px) 필수.
- 스크린리더: 칩 `aria-pressed`, 토글 `aria-checked`, 시트 `role=dialog aria-modal`, 스트리밍 영역 `aria-live=polite` (프로토타입 미구현, 구현 시 필수).
- 상태 매트릭스(PRD §3.2)의 8개 상태 중 프로토타입은 근거 부족·권한 거부·철회·판본 충돌·공유 불가를 구현했고, 네트워크 실패·오프라인·인증 만료는 구현 단계에서 추가한다.

## 6. `apps/web` 구현 시 매핑 `[제안]`

- 토큰은 `apps/web/src/app/globals.css` 에 `[data-app=hoondok]` 스코프로 추가해 기존 `.dark`/paper 토큰과 충돌하지 않게 한다.
- 서체: Noto Serif KR 은 이미 `--font-reading` 으로 로드됨. IBM Plex Mono 만 추가.
- 아이콘: lucide-react 사용(프로토타입 인라인 SVG 와 동일 계열).
- 라우트: `(hoondok)` 라우트 그룹으로 분리해 `(chat)` 화면과 레이아웃·AuthGuard 를 공유하지 않는다.
