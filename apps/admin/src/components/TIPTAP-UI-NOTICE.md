`tiptap-ui`, `tiptap-ui-primitive`, `tiptap-icons`, `tiptap-node`, related hooks, utility and SCSS files use the provided Tiptap Simple Editor components. The initial component dependency closure was copied from the installed template in the local `ffwpu-social` project and compared with the current upstream Simple Editor template on 2026-10-31.

Service adapters preserve managed asset identifiers, omit temporary image-upload nodes from saved documents, use the server's supported font/color values, and scope CSS tokens to the editor and its portals. The surrounding source selection and publication workflow remains application-owned.
